# 🎮 Online GBA Emulator (Work in Progress)

> [!NOTE]  
> This project is currently a **Work in Progress**. New features and games are being added regularly!

A free, high-performance web-based emulator featuring a curated library of over **150+ classic games** ready to play in your browser.

**🚀 [Play Now at gba.davidthompson.dev](https://gba.davidthompson.dev/)**

---

## ✨ Features
* **Massive Library:** Over 150 Game Boy Advance titles available instantly.
* **Save Support:** Save your progress and pick up where you left off.
* **Browser Based:** No downloads required—works on Chrome, Firefox, and Safari.
* **Custom Engine:** High-speed emulation for smooth gameplay.

## 🛠️ Project Status
* **Hosting:** This site has moved from GitHub Pages and is now officially hosted on **Vercel** for better performance.
* **Active Development:** Expect frequent updates to the UI and game library.

## 🕹️ How to Play
1. Visit the [Live Site](https://gba.davidthompson.dev/).
2. Browse the game library.
3. Click a title to load the engine and start playing!
